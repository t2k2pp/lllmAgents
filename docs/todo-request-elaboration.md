## 第 4 段: 回数・文字数のブレーキを撤廃し、ループ点検へ（ユーザー指摘 2026-10-14）

指摘: 「能力の低いモデルのループ対策でブレーキが入ったのだろうが、 12,000 字や回数で止めるのは本当に必要か。
一定回数ごとにループしていないかを点検し、 不必要なユーザー確認はしない仕組みがいるのでは。 Claude Code はこんな制限をしていないのでは」

Claude Code の実態（回答済み）: 対話モードに作業回数・文字数の上限は無い。 回数上限は非対話 (`claude -p` / SDK) の
`--max-turns` / `maxTurns` だけで、 利用者が明示的に付ける任意設定。 長さで切るのは出力の切り詰め（bash 出力・ファイル読み込み）で、
コンテキスト保護であって作業のブレーキではない。
