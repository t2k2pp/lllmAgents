# ASCIIアート化スキル設計

更新日: 2026-05-16

## 目的

画像ファイルを入力として受け取り、固定的なプログラム手順でテキストのASCIIアートへ変換するスキルを提供する。

このスキルの狙いは、毎回アドホックに文字を並べるのではなく、**決定的な変換手順**で再現可能なASCIIアートを生成することにある。

## ユースケース

- 画像をターミナルで見やすいASCIIアートにしたい
- PNG/JPG/WebP などの画像を文字ベースのプレビューへ変換したい
- 画像の雰囲気を保ったまま Markdown / txt に埋め込みたい
- 複数の文字セットや横幅で比較出力したい

## 提供方式

builtin skill として `src/skills/builtin/ascii-art/SKILL.md` を追加する。

スキル本体は **固定ワークフロー指示**で構成し、実処理は Node.js または Python の短い変換スクリプトを同梱する余地を持つ。
初版ではまず SKILL.md にワークフローを定義し、利用時に必要なら同じディレクトリへ変換スクリプトを生成して実行する方針とする。

## スキルトリガー

以下のような依頼で発火する想定:

- 画像をASCIIアートにして
- このPNGを文字絵にして
- ターミナル表示向けに画像を白黒文字化して
- 画像を `@#*.` みたいな文字で表現して
- アスキーアート化してテキスト保存して

## 基本仕様

### 入力
- ローカル画像ファイルの絶対パス
- 任意で出力先の絶対パス
- 任意で横幅（例: 40 / 80 / 120）
- 任意で文字セット
- 任意でカラー保持の有無

### 出力
- プレーンテキストの `.txt`
- 必要なら Markdown fenced code block を含む `.md`
- 生成に使ったスクリプトを同じディレクトリへ保存

## 変換アルゴリズム

### 標準モード
1. 画像を読み込む
2. グレースケールへ変換
3. アスペクト比を保って横幅基準でリサイズする
4. 文字セルの縦横比補正を行う（一般的に高さを0.45〜0.55倍）
5. 輝度を濃度順文字セットへ写像する
6. 行ごとに連結してテキスト化する
7. `.txt` に保存する

### 推奨デフォルト値
- 横幅: 80
- 文字セット: `@%#*+=-:. `
- 縦横比補正: 0.5
- 出力先: `sandbox/` 配下

## 品質ルール

- ユーザー成果物は必ず `sandbox/` 配下に出す
- 相対パスではなく絶対パスを使う
- 画像そのものを改変せず、生成物を別ファイルとして保存する
- 生成スクリプトは再利用のため成果物と同ディレクトリに残す
- 単に本文へASCIIを貼って終わらず、必ずファイル保存する

## 実装方針

### 初版
- SKILL.md のみ追加
- 利用時にエージェントが `file_write` で変換スクリプトを書き出し、`bash` で実行
- Python が使える場合は Pillow を優先
- Pillow が未導入なら `pip install pillow` を案内または実行

### 将来拡張
- スキル同梱 `scripts/image_to_ascii.py`
- ANSIカラーASCII対応
- エッジ強調モード
- 2値化モード
- Braille / Block elements への拡張

## 運用手順

1. ユーザーから画像パス・出力先・幅指定を確認（明示済みなら省略）
2. 入力画像の存在を確認
3. 変換スクリプトを出力先と同ディレクトリへ保存
4. スクリプトを実行して `.txt` を生成
5. 生成物の先頭数行を確認して破綻がないか軽く検証
6. 保存先パスを報告

## 受け入れ基準

- 画像→ASCII変換の固定手順が明文化されている
- 出力がファイルとして保存される
- 生成スクリプトも保存され再利用可能
- sandbox出力と絶対パス運用のルールが明記されている
- スキル説明文だけで発火条件が分かる

## 備考

このスキルは「美しく手打ちのASCIIアートを創作する」ものではなく、
**画像を規則的にテキスト濃淡へ写像するユーティリティスキル**として定義する。
そのため自由作画よりも、再現性・保存・再実行性を重視する。
