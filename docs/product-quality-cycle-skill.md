# 商品品質改善サイクルスキル設計

Status: implemented

## 目的

商品レベルを目指すレビューを単発の指摘で終わらせず、任意の観点について「レビュー → 修正・改善設計 → 実装 → 評価 → 記録」を再現可能にする。

## 呼び出し

組み込みスキル `product-quality-cycle` は、たとえば次の依頼で使用する。

> 信頼性の観点でレビュー、修整・改善の設計、実装・評価のサイクルを回して。

観点にはセキュリティ、UX、自律性、可観測性、性能、リリース品質、最近追加した機能などを指定できる。「商品レベル」のみの場合は、正しさ・安全性・運用性・UX・配布可能性を横断する。

## 既存スキルとの境界

- `code-review`: 指摘と修正案を返すレビュー専用
- `dev-workflow`: 範囲が明確な通常の実装・バグ修正
- `product-quality-cycle`: 設計・履歴・実行ログ・配布物まで調べ、改善を実装して前後評価と記録まで行う

## 安全条件

- 実行ログのプロンプトと応答は既定でレビュー文書へ転載しない。
- 未コミットのユーザー変更を変更・stageしない。
- commit、タグ、push は明示依頼がある場合だけ実施する。
- before タグは変更前 HEAD、after タグは全検証を通した commit を指す。

## 配布

スキル本体は `src/skills/builtin/product-quality-cycle/SKILL.md` に置く。`build:deploy` とインストーラーの既存 skill 配布経路により、他の組み込みスキルと同様に利用可能になる。
