## 5-1 ベクトルデータベースの選定と導入

### ベクトルデータベースとは

ベクトルデータベースは、ベクトル（数値の系列）を効率的に検索・保存するためのデータベースです。

#### 基本概念

```
テキスト → エンバーディング → ベクトル → 検索 → 関連テキスト
"アップルの株価" → [0.23, -0.45, ...] → 類似度計算 → "Apple 株価上昇"
```

#### 主要なベクトルデータベース

**1. Pinecone**:
```
- マネージドサービス
- 簡単導入
- 高コスト
```

**2. Weaviate**:
```
- オープンソース
-/self-hosted 可能
- 柔軟性
```

**3. Milvus**:
```
- 大規模データ対応
- 分散サポート
- 複雑な設定
```

**4. Chroma**:
```
- 軽量
- 開発者フレンドリー
- 小規模向け
```

### 選定ガイドライン

#### 比較サマリー

| 項目 | Pinecone | Weaviate | Milvus | Chroma |
|------|----------|----------|--------|-------|
| 導入の容易さ | 高 | 中 | 低 | 高 |
| スケーラビリティ | 高 | 中 | 高 | 低 |
| コスト | 高 | 低 | 低 | 低 |
| 機能 | 高 | 高 | 高 | 中 |

#### 選定フロー

```
小規模・開発 → Chroma
中規模・柔軟性 → Weaviate
大規模・分散 → Milvus
マネージド・簡単 → Pinecone
```

```python
import PyPDF2

def extract_text_from_pdf(pdf_path):
    text = ""
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            text += page.extract_text()
    return text
```

### データ前処理

#### テキストクリーニング

```python
import re

def clean_text(text):
    # 大文字化
    text = text.lower()
    
    # 特殊文字削除
    text = re.sub(r'[^\w\s]', '', text)
    
    # 複数スペース削除
    text = re.sub(r'\s+', ' ', text)
    
    # 短すぎる単語削除
    words = text.split()
    text = ' '.join([w for w in words if len(w) > 2])
    
    return text
```

#### チャンキング（分割）

**固定サイズチャンキング**:
```python
def fixed_size_chunking(text, chunk_size=500, overlap=50):
    chunks = []
    for i in range(0, len(text), chunk_size - overlap):
        chunk = text[i:i + chunk_size]
        if chunk:
            chunks.append(chunk)
    return chunks
```

**意味ベースチャンキング**:
```python
def semantic_chunking(text, sentences):
```

## 5-3 検索最適化とランキング

### 検索アルゴリズム

#### 類似度検索

**コサイン類似度**:
```python
import numpy as np

def cosine_similarity(vec1, vec2):
    return np.dot(vec1, vec2) / (
        np.linalg.norm(vec1) * np.linalg.norm(vec2)
    )
```

**ユークリッド距離**:
```python
def euclidean_distance(vec1, vec2):
    return np.sqrt(np.sum((vec1 - vec2) ** 2))
```

#### ハイブリッド検索

**キーワード + ベクトル**:
```python
def hybrid_search(query, docs):
    # キーワード検索
    keyword_scores = bm25_search(query, docs)
    
    # ベクトル検索
    vector_scores = vector_search(query, docs)
    
    # 統合（重み付き）
    final_scores = 0.3 * keyword_scores + 0.7 * vector_scores
    
    return sorted(docs, key=lambda x: final_scores[x], reverse=True)
```

### ランキング最適化

#### 再ランキング

```python
def rerank(results, query):
    # Cross-Encoder で再評価
    from sentence_transformers import CrossEncoder
    
    model = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')
    scores = model.predict([[query, doc] for doc in results])
    
    return sorted(
        zip(results, scores),
        key=lambda x: x[1],
        reverse=True
    )
```

### 検索結果の評価

#### 評価指標

**1. Precision@K**:
```python
def precision_at_k(relevant_docs, retrieved_docs, k):
    relevant_in_top_k = len(set(relevant_docs) & set(retrieved_docs[:k]))
    return relevant_in_top_k / k
```

**2. Recall@K**:
```python
def recall_at_k(relevant_docs, retrieved_docs, k):
    relevant_in_top_k = len(set(relevant_docs) & set(retrieved_docs[:k]))
    return relevant_in_top_k / len(relevant_docs)
```

**3. MRR (Mean Reciprocal Rank)**:
```python
def mrr(relevant_rank):
    return 1 / relevant_rank if relevant_rank > 0 else 0
```
