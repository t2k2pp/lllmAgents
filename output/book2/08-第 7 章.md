## 7-1 プロンプトエンジニアリングの基礎

### プロンプト設計の原則

#### 1. 明確性

**悪い例**:
```
"会社について教えて"
```

**良い例**:
```
"当社のビジョン、ミッション、主要製品について、300 文字以内で説明してください"
```

#### 2. 文脈の提供

**基本構造**:
```
┌──────────────┐
│ システムロール │
├──────────────┤
│ 文脈          │
├──────────────┤
│ 具体的な指示  │
├──────────────┤
│ 出力形式      │
└──────────────┘
```

**実装例**:
```python
prompt_template = """
あなたは企業のサポートアシスタントです。
次の情報に基づいて回答してください。

会社情報：
- 社名：ABC 株式会社
- ビジョン：テクノロジーで社会を革新する
- 主要製品：AI 分析ツール、クラウドストレージ

ユーザーの質問：{question}

回答は以下の形式で：
1. 簡潔な回答（50 文字以内）
2. 詳細な説明（200 文字以内）
3. 関連する製品
"""
```

#### 3. 制約の設定

```python
prompt = """
以下の制約で回答してください：
- 文字数：200 文字以内
- 専門用語は避けると
- 具体的な例を含める
- 敬語を使用
"""
```

## 7-2 評価とテストの自動化

### 評価指標

#### 1. 精度指標

**正確性**:
```python
def evaluate_accuracy(model, test_cases):
    correct = 0
    for input_text, expected_output in test_cases:
        prediction = model.generate(input_text)
        if prediction == expected_output:
            correct += 1
    return correct / len(test_cases)
```

**関連性**:
```python
def evaluate_relevance(model, queries, relevance_scores):
    scores = []
    for query, expected_score in zip(queries, relevance_scores):
        response = model.generate(query)
        predicted_score = relevance_model.score(response)
        scores.append(abs(predicted_score - expected_score))
    return scores
```

#### 2. 品質指標

**一貫性**:
```python
def evaluate_consistency(model, prompt):
    responses = [model.generate(prompt) for _ in range(10)]
    # 応答の類似度を計算
    similarity_scores = []
    for i in range(len(responses)):
        for j in range(i+1, len(responses)):
            score = cosine_similarity(responses[i], responses[j])
            similarity_scores.append(score)
    return sum(similarity_scores) / len(similarity_scores)
```

**有用性**:
```python
def evaluate_usefulness(model, tasks):
    success_count = 0
    for task in tasks:
        response = model.generate(task['prompt'])
        if task['validator'](response):
            success_count += 1
    return success_count / len(tasks)
```

### 自動評価パイプライン

```python
class EvaluationPipeline:
    def __init__(self):
        self.metrics = [
            AccuracyMetric(),
            RelevanceMetric(),
            ConsistencyMetric(),
            UsefulnessMetric()
        ]
    
    def evaluate(self, model, test_dataset):
        results = {}
        
        for metric in self.metrics:
            results[metric.name] = metric.compute(model, test_dataset)
        
        return results
```

class PromptVersioning:
    def __init__(self):
        self.versions = {}
    
    def save_version(self, name, prompt, version):
        self.versions[f"{name}:{version}"] = {
            'prompt': prompt,
            'created_at': datetime.now(),
            'metadata': {}
        }
    
    def get_version(self, name, version):
        return self.versions.get(f"{name}:{version}")
    
    def get_latest(self, name):
        versions = [k for k in self.versions if k.startswith(f"{name}:")]
        if not versions:
            return None
        latest = max(versions, key=lambda x: x.split(':')[1])
        return self.versions[latest]
```

#### パフォーマンスモニタリング

from prometheus_client import Counter, Histogram, start_http_server

# メトリクス定義
REQUEST_COUNT = Counter('llm_requests_total', 'Total LLM requests')
LATENCY = Histogram('llm_latency_seconds', 'LLM latency')

def monitor_request(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        REQUEST_COUNT.inc()
        start_time = time.time()
        try:
            result = func(*args, **kwargs)
            return result
        finally:
            LATENCY.observe(time.time() - start_time)
    return wrapper
```

#### 異常検知

```python
class AnomalyDetector:
    def __init__(self, window_size=100):
        self.window = []
        self.window_size = window_size
    
    def add_observation(self, value):
        self.window.append(value)
        if len(self.window) > self.window_size:
            self.window.pop(0)
    
    def is_anomaly(self, value):
        if len(self.window) < 10:
            return False
        
        mean = sum(self.window) / len(self.window)
        std = (sum((x - mean) ** 2 for x in self.window) / len(self.window)) ** 0.5
        
        z_score = abs(value - mean) / std if std > 0 else 0
        
        return z_score > 3  # 3 シグマルール
```
