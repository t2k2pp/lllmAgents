# 様式の手引き（建物・乗り物）

「〇〇らしく」見せるのは、全体の形より **見分けどころ（屋根の形・壁の材料・窓・飾り）** の組み合わせ。
作る前に、その様式の見分けどころを 4〜6 個選んで表に書き、それぞれを bkit の何で作るか決める。
ここに無い様式は `web_search` で写真の説明を調べ、同じ形で見分けどころを書き出してから作る。

bkit での作り方の定番:
- 瓦・板・下見板・格子・手すり・石積み → 細い `box` を `repeat` で並べる（数が多いので 1 本ずつ作らず repeat）
- 屋根 → 妻の三角は `prism`（plane="XZ"）、屋根面は傾けた `box`。入母屋・寄棟は屋根面の box を 4 枚にする
- 窓・戸口・狭間 → `cut` で抜き、奥にガラス・戸の `box`
- 円塔・煙突・柱 → `cylinder`（円すい屋根は radius_top=0）
- 反り（城の石垣・屋根の反り）→ 断面を並べる `hull` か、少しずつ傾けた box を重ねる
