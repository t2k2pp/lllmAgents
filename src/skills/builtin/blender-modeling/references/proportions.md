# 寸法の目安

形づくりの出発点にする目安（実物にはばらつきがある）。まず表を書き、撮った絵と比べて直す。
単位は m。H = 体高（き甲〔首の付け根の背の一番高い所〕までの高さ）。

## 馬（乗用馬・H = 1.6m）

| 所 | 目安 | 1.6m の時 |
|:--|:--|:--|
| 体長（肩の先〜尻の先） | ≒ H | 1.6 |
| 尻の高さ | ≒ H（±3%） | 1.6 |
| 胴の深さ（き甲〜胸の下） | ≒ 0.45H | 0.72 |
| 胸の下から地面まで | ≒ 胴の深さ（同じくらいが釣り合い） | 0.8〜0.9 |
| 胴の幅（いちばん太い所） | ≒ 0.32H | 0.5 |
| 頭の長さ（耳の付け根〜鼻先） | ≒ 0.38H | 0.6 |
| 首の上の線の長さ | ≒ 0.45H | 0.7 |
| 首の角度 | 水平から 40〜50 度で上がる | |
| 頭の角度 | 鼻先が下。顔の線は垂直から 30〜45 度 | |
| 耳 | 長さ ≒ 0.1H、前を向いて立つ | 0.15 |
| 前脚 ひじの高さ | ≒ 0.6H | 0.95 |
| 前脚 前ひざ（手根）の高さ | ≒ 0.3H | 0.5 |
| 後ろ脚 ひざ（膝）の高さ | ≒ 0.62H（腹の横、前へ出る） | 1.0 |
| 後ろ脚 飛節の高さ | ≒ 0.35H（後ろへ突き出る） | 0.55 |
| 球節の高さ | ≒ 0.12H | 0.2 |
| ひづめの高さ | ≒ 0.05H | 0.08 |
| 管（前ひざ・飛節の下）の太さ | 半径 ≒ 0.025H | 0.04 |
| 尾 | 尻の上から下がる。毛は飛節の下まで | |

形の要点:
- 前脚は横から見てほぼまっすぐ。前ひざは前へ曲がる（曲げる時）。
- 後ろ脚は ひざ が前・飛節 が後ろの「く」の字。飛節から下（管）は垂直。
- つなぎ（球節〜ひづめ）は前へ 50〜55 度傾く。
- 背の線は き甲 が少し高く、背でわずかに下がり、腰〜尻で丸く上がる。腹の線は胸から後ろへゆるく上がる。
- 胸は前から見て幅があり、前脚は胸の両側から下りる（脚の間に胸の幅ぶんのすき間）。

## 四つ足の動物の共通

- 前脚: 肩 → ひじ（後ろ向きに曲がる）→ 手首（人の手首。馬・牛では「前ひざ」と呼ぶ）→ 指。
- 後ろ脚: 腰 → ひざ（前へ）→ かかと（飛節。後ろへ）→ 指。**かかとは地面から離れている**（犬・猫・馬・牛・鹿）。
- 歩く時に地面に付くのは指先（犬・猫）かひづめ（馬・牛・鹿）。
- 目安（体高 H に対して）:

| 動物 | 体長 | 頭の長さ | 胴の深さ | 脚の付け根からの脚の長さ |
|:--|:--|:--|:--|:--|
| 犬（中型） | 1.1〜1.2H | 0.4H | 0.45H | 0.55H |
| 猫 | 1.5H | 0.4H | 0.45H | 0.55H |
| 牛 | 1.3〜1.5H | 0.4H | 0.55H（深い） | 0.45H（短め） |
| 鹿 | 1.1H | 0.3H | 0.4H | 0.6H（長い） |

## 人

- 身長 = 頭 7〜8 個（子どもは 5〜6 個）。
- 股下 ≒ 身長の半分。肩幅 ≒ 頭 2 個。ひじ ≒ へそ の高さ。手首 ≒ 股 の高さ。
- ひざ ≒ 股と足の裏の中ほど。
