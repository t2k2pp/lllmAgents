# 手本帳（自分で手本を増やす）

うまく作れた物は「手本帳」に残し、次に似た物を頼まれた時の出発点にする。使うほど作れる物が増える。

## 置き場所

1. 作業フォルダ（またはその上）に `blender-library/` があれば、そこ（Git で残したい時はこちら。ユーザーのリポジトリに入る）。
2. 無ければ `~/.localllm/blender-library/`（このパソコンだけ）。

ユーザーが「Git に残したい」と言ったら 1 を作る。

## 形

```
blender-library/
  INDEX.md                  # 1 行 1 つ: - <名前> — <何か>（様式・大きさ）: <フォルダ>
  <名前>/                    # 名前は英小文字とハイフン（例 edo-machiya, showa-house, fishing-boat）
    build.py                # これだけで作れるスクリプト（bkit を使う。下の「build.py の決まり」）
    notes.md                # 寸法の表・見分けどころ・つまずいた所・効いた書き方・残った問題
    preview_three_quarter.png  # 確かめの絵（斜め 1 枚でよい）
```

## 作る前に（毎回）

1. `INDEX.md` を読み、同じ物か近い物（同じ様式・同じ形の仲間）を探す。
2. あれば その `build.py` と `notes.md` を読み、作業フォルダにコピーして直す（手本帳の中は書き換えない）。
3. 無ければ `examples/` のいちばん近い物から始める。

## 残す時（ユーザーが良いと言った時・または目と数値で確かめ終えた時）

1. `<名前>/build.py` に、作ったスクリプトを保存する。
2. `notes.md` に書く:
   - 寸法の表（m）と、出典（調べたページ・ユーザーの指示）
   - 様式の見分けどころと、それぞれを bkit の何で作ったか
   - つまずいた所と直し方（例「屋根の box の傾きの符号が逆だった」「髪が額にかかった → 後ろへ 2cm」）
   - 残った問題
3. 確かめの絵を 1 枚コピーする。
4. `INDEX.md` に 1 行足す。
5. 報告で「手本帳に残した（場所）」と伝える。

**残さない物**: ユーザーが良くないと言った物・確かめていない物・実在の商標やロゴ・実在の人の顔。

## build.py の決まり

- 先頭で bkit を読み込む:
  ```python
  import os, sys
  BKIT = os.path.expanduser("~/.localllm/skills/blender-modeling/references")
  sys.path.insert(0, BKIT)
  from bkit import *
  ```
- `build()` 関数が物を作って返す。`if __name__ == "__main__":` の中で 撮る・書き出す（examples と同じ形）。
- 寸法は先頭に名前付きの定数で書く（次に直す人が数値だけ変えられるように）。
- bkit に無い道具を作ったら build.py の中に書く。何度も使いそうなら notes.md に「bkit に足すとよい」と書く（スキルの作者が取り込む）。
