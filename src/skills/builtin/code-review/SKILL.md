# Code Review

## 手順
1. **対象の把握**: file_read / glob / grep でレビュー対象ファイルと影響範囲を確認
2. **観点の参照**: `references/code-review-criteria.md` の重要度分類・チェック観点・出力形式・報告ルールに従う
3. **指摘**: 観点に従って問題を発見 → 重要度を付与 → ファイルパスと行番号を明記 → 修正案を添える
4. **報告**: 重要度が高い順にまとめる

## 用途分担

| ツール | 用途 |
|--------|------|
| `code-review` (本スキル) | ユーザーが「コードをレビューして」 と任意ファイル / 任意範囲のレビューを依頼したとき |
| `pr-review` (skill) | git diff ベースの PR レビュー |
| `code-reviewer` (agent / task ツール経由) | メインLLM が自律判断でコードレビューを別コンテキストで実行したいとき |

詳細な観点・形式は **`references/code-review-criteria.md`** を必ず参照すること。
